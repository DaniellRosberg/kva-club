# 🐸 Ква-клуб

Добрый игровой пруд для Иры, 4 года.

## Играть

**https://daniellrosberg.github.io/kva-club/**

- Найди четыре пары картинок.
- Придумай песенку на музыкальных кувшинках.
- Раскрась жабку и сохрани рисунок.
- Посчитай светлячков от 1 до 5.
- Поздоровайся с жабкой и поменяй погоду у пруда.

Крупные кнопки, поддержка телефонов и клавиатуры, звук по желанию. Без рекламы, аналитики, регистрации и внешних ресурсов. Фотографии ребёнка не используются.

## Устройство

`index.html` — весь сайт: HTML, CSS, JavaScript и SVG. Сборка и установка пакетов не нужны. Можно открыть локально в браузере или запустить `python3 -m http.server 4173`.

Публикация: GitHub Pages, ветка `main`, папка `/(root)`.
